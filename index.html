Oct 6, 2026

Power-user tricks for Muse Spark

The clever ways to use an AI agent: give it recurring scheduled jobs, hand it big jobs and walk away while it works in the background, teach it preferences once via memory, use side chats per topic, connect apps so it can act not just talk.

Oct 6, 2026

Agent payments, honestly assessed

AI agents can buy things, but every purchase needs explicit approval of the exact terms, approvals cannot be pre-granted or automated, and merchants get one-time credentials instead of the real card. Small routine purchases are fine today; big ones still deserve human eyes. The future is agent-native checkout rails.

Time zones

8:30pm in New York is 9:30am next day in Tokyo and 8:30am in China. US daylight saving ends Nov 1, 2026, which slides those times an hour later.

Oct 10, 2026

The kernel keyring experiment

Li wanted to hand over an API key via the Linux kernel keyring instead of chat or disk. The gotcha: keys added straight to the shared user keyring are unreadable even by their creator due to a kernel permission catch-22. The working recipe: add to the session keyring first (creator becomes possessor), setperm to grant the user access, then link into the user keyring. Keys live in RAM only and vanish on reboot.

Oct 10, 2026

No user terminal in Muse

The VM shell is the agents tool only; there is no user-facing terminal in the Muse app. An unofficial third-party project called muse-console adds a web terminal via tunneling, but it is a hobbyist hack.

Oct 10, 2026

Secure Vault + OpenRouter

The realistic path for the API key: Muse Secure Vault, where the key is entered on a secure page the agent never sees. OpenRouter was connected that way, a workspace skill was built to call it, and a scan found 19 free models.

FreeToken-Bots skill research

A skill that discovers zero-price OpenRouter models for Pi child-agent coding workflows. Notable for its fail-closed safety design: it refuses to probe any model not in the verified-free scan, because dropping the ":free" suffix silently routes to the paid variant.

A free giant for Pi

Probed nvidia/nemotron-3-ultra-550b:free on OpenRouter at $0: it answered PONG and its tool-call smoke test correctly invoked a calculator with the right arguments. A 550B-parameter model with 1M context, free — a solid pick to wire into Pi.

Oct 11, 2026

Proxycurl is dead; TikHub gutted its LinkedIn API

Research for jobs.feedos.si data collection turned up two surprises: Proxycurl shut down (its founder's successor is NinjaPear), and TikHub silently removed its LinkedIn API in October 2026. Cheapest viable path for 50k profiles: roughly $75-175 via Bright Data or Apify actors. For job listings, TheirStack has a free tier of 200 credits a month.
